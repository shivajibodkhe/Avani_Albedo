☁️ Paid Google Cloud Infrastructure & 1-Click Hosting Guide

Architecture blueprint, serverless Cloud Run containerization, Firestore Native, and deployment instructions for your paid GCP project.

🚀 1. Cloud Run (Serverless API & Solver)

Executes the containerized FastAPI backend and Google OR-Tools SCIP mathematical solver. Auto-scales 0 to 10 instances with sub-50ms execution latency.

🔥 2. Cloud Firestore (Native Mode Database)

Persists municipal climate action plans in avani_scenarios and administrative logs in avani_audit with zero maintenance.

🤖 3. Vertex AI (Gemini 2.5 Flash Agent)

Generates persona-tailored municipal climate action plans, thermodynamic justifications, and 3-phase implementation roadmaps directly on GCP.

🌐 4. Firebase Hosting (Global Edge CDN)

Serves ultra-fast dark-mode Leaflet GIS assets globally with built-in SSL and reverse-proxy routing to Cloud Run APIs via firebase.json.

⚡ 1-Command Automated Deployment (Local Terminal)

We have created a ready-to-run deployment script deploy_gcp.sh in the project root. Run this in your terminal:

chmod +x deploy_gcp.sh && ./deploy_gcp.sh YOUR_GCP_PROJECT_ID

📋 Manual Step-by-Step gcloud Commands

  1. Authenticate & Set Project:
    gcloud auth login && gcloud config set project YOUR_PROJECT_ID
  2. Enable Core GCP APIs:
    gcloud services enable run.googleapis.com cloudbuild.googleapis.com firestore.googleapis.com aiplatform.googleapis.com
  3. Deploy to Cloud Run:
    gcloud run deploy avani-albedo --source . --region asia-south1 --allow-unauthenticated
  4. Deploy Firebase Hosting Frontend:
    firebase deploy --only hosting
